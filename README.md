# Network & System Automation Scripts

A collection of lightweight scripts, configurations, and automation utilities for custom network routing, performance optimization, and system management.

## Features
- **Network Optimization:** Custom routing rules and configuration templates for advanced network managers (Singbox/Xray protocols).
- **System Automation:** Shell and Termux-compatible scripts to streamline repetitive system tasks and environment setups.
- **Portability:** Designed to work efficiently in low-resource environments.

## How to Use
Clone this repository to your local environment:
```bash
git clone https://github.com/Ryu-dev99/Ryu_project.git
```
